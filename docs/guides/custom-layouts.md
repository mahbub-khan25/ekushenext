# নিজের কীবোর্ড লেআউট

একুশেতে ফোনেটিক আর ইউনিজয়, জাতীয়, প্রভাত, বর্ণনা, মুনীর অপটিমা লেআউট তৈরি থাকে। এর বাইরে অন্য কোনো সাজানোয় অভ্যস্ত হলে একটি **লেআউট ফাইল** (`.ekushe-layout`) দিয়ে সেটিও চালু করা যায়: অফিসের নিজের সাজানো, কারও বানিয়ে দেওয়া, বা নিজের বানানো।

## ফাইল যোগ করা

- **উইন্ডোজ, ম্যাক, লিনাক্স:** একুশে স্টুডিও → সেটিংস → কীবোর্ড লেআউট → **লেআউট ফাইল যোগ করুন**।
- **অ্যান্ড্রয়েড:** একুশে অ্যাপ → কীবোর্ড লেআউট → **লেআউট ফাইল যোগ করুন**।

যোগ করার পর তালিকায় নামটি আসবে; বেছে নিলেই চালু। টাস্কবার, মেনু আর কী-ম্যাপে সেই নামই দেখাবে। ফাইলটি কোনো প্রোগ্রাম নয়, শুধু কোন কী-তে কোন অক্ষর তার তালিকা; একুশে যোগ করার আগে পুরোটা যাচাই করে নেয়।

একুশের ব্যাকআপে যোগ করা লেআউটও থাকে, তাই নতুন কম্পিউটারে ব্যাকআপ দিলে লেআউটও ফিরে আসে।

## নিজে বানানো

সবচেয়ে সহজ পথ: কাছাকাছি একটি লেআউট বেছে **স্টুডিও → সেটিংস → এই লেআউট ফাইল হিসেবে নিন**, তারপর যেকোনো টেক্সট এডিটরে (Notepad) বদলে আবার যোগ করুন।

```json
{
  "format": "ekushe-layout",
  "version": 1,
  "name": "আমার লেআউট",
  "short": "আমার",
  "author": "",
  "description": "",
  "link_key": "g",
  "reph_after": false,
  "keys":     { "j": "ক", "J": "খ", "f": "া", "d": "ি", "...": "..." },
  "altgr":    { "d": "ই", "...": "..." },
  "after_link": { "...": "..." }
}
```

- **keys:** সাধারণ ও Shift-সহ কী (বড় হাতের অক্ষর মানে Shift)।
- **altgr:** ডান Alt (AltGr) চেপে, ম্যাকে Option চেপে, অ্যান্ড্রয়েডে কী চেপে ধরে।
- **link_key:** যুক্তাক্ষরের লিংক কী (হসন্ত দিয়ে পরের অক্ষর জোড়ে)।
- **after_link:** লিংক কী-র পরে কোনো কী চাপলে যা আসবে, যেখানে সেটা কারের পূর্ণ স্বরবর্ণ নয় (লিংক কী + া = আ নিজে থেকেই হয়)।
- **reph_after:** রেফ অক্ষরের পরে দেওয়া হয় কি না।

নিয়ম: ফাইল ৬৪ KB-র কম, প্রতিটি কী একটি ইংরেজি অক্ষর বা চিহ্ন, মান ১ থেকে ৮টি অক্ষর, অন্তত ১০টি বাংলা কী।
