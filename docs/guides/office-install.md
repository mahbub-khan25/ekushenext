# অফিসের সব কম্পিউটারে একসাথে (আইটি বিভাগের জন্য)

একুশে নেক্সট প্রতিটি ব্যবহারকারীর নিজের ফোল্ডারে ইনস্টল হয় (`%LOCALAPPDATA%\Programs\Ekushe`), তাই অ্যাডমিন অধিকার লাগে না। সব কম্পিউটারে একই সেটিংস (লেআউট, বিজয় আউটপুটের অ্যাপ, শর্টকাট, নিজস্ব লেআউট ফাইল) দিয়ে নীরবে ইনস্টল করা যায়।

## ১. একটি কম্পিউটার সাজিয়ে নিন

একুশে ইনস্টল করে স্টুডিওতে যেভাবে চান সাজান, তারপর **সেটিংস → ব্যাকআপ নিন**। ফাইলটির নাম দিন `ekushe-settings.json`।

## ২. নীরব ইনস্টল

```
Ekushe-Setup.exe /S --settings \\server\share\ekushe-settings.json
```

অথবা `ekushe-settings.json` ফাইলটি `Ekushe-Setup.exe`-এর পাশে (একই শেয়ার্ড ফোল্ডারে) রাখুন; তখন `/S` দিলেই, বা কেউ ডাবল-ক্লিক করে ইনস্টল করলেও, ওই সেটিংস নিজে থেকে বসে যাবে।

| সুইচ | কাজ |
|---|---|
| `/S`, `/silent`, `/quiet`, `--auto-install` | কোনো জানালা ছাড়া ইনস্টল |
| `--settings <ফাইল>` | এই সেটিংস দিয়ে (স্টুডিওর ব্যাকআপ, বা একটি `config.toml`) |
| `--no-launch` | ইনস্টলের পর একুশে চালু করবে না |
| `--no-desktop-shortcut` | ডেস্কটপে শর্টকাট নয় |
| `--no-startup` | উইন্ডোজ চালু হলে একুশে নিজে চালু হবে না |

সফল হলে exit code 0; সেটিংস ফাইল নষ্ট থাকলে বা পড়া না গেলে 1, আর কারণ লেখা থাকে `%TEMP%\ekushe-install.log`-এ। আগে থেকে একুশে চালু থাকলে সেটিকে বন্ধ করতে বলে, তারপর হালনাগাদ করে।

Intune, SCCM বা লগইন স্ক্রিপ্টে ব্যবহারকারীর নিজের পরিচয়ে (user context) চালান, কারণ ইনস্টল প্রতিটি ব্যবহারকারীর নিজের।

## ৩. সরানো

```
"%LOCALAPPDATA%\Programs\Ekushe\ekushe.exe" --uninstall
```
